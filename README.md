# 📚 মেধাকোষ (MedhaKosh) — ফ্রি ব্লগ ও ফাইল ডাউনলোড ওয়েবসাইট

একটি সম্পূর্ণ আধুনিক, রেসপনসিভ এবং ১০০% বিনামূল্যে পরিচালিত ব্লগ ও ডিজিটাল রিসোর্স প্ল্যাটফর্ম।

---

## 🚀 কীভাবে এখনই নিজের কম্পিউটারে ওয়েবসাইটটি দেখবেন?

১. আপনার কম্পিউটারের ফাইল এক্সপ্লোরার থেকে `i:\Free Website` ফোল্ডারে যান।  
২. সরাসরি **`index.html`** ফাইলে ডাবল-ক্লিক (Double-click) করুন।  
৩. আপনার ব্রাউজারে (Chrome / Edge / Firefox) সম্পূর্ণ ওয়েবসাইটটি লাইভ চালু হয়ে যাবে!

---

## 📂 ফাইলগুলোর পরিচিতি

* **`index.html`** — ওয়েবসাইটের মূল গঠন ও লেআউট (Navbar, Hero, Blog Grid, Download Hub, Modals, Footer)।
* **`style.css`** — কাস্টম ডিজাইন, অ্যানিমেশন ও স্ক্রলবার স্টাইল।
* **`data.js`** — **সবচেয়ে গুরুত্বপূর্ণ ফাইল!** এখানে আপনার সব ব্লগ পোস্ট এবং ফাইল ডাউনলোডের তথ্য সংরক্ষিত আছে। নতুন কোনো পোস্ট বা ফাইল যোগ করতে চাইলে শুধু এই ফাইলটি এডিট করলেই হবে।
* **`app.js`** — লাইভ সার্চ, ক্যাটাগরি ফিল্টার, ডার্ক/লাইট মোড এবং ডাউনলোড লজিক।

---

## ✍️ কীভাবে নতুন ব্লগ পোস্ট বা ডাউনলোড ফাইল যুক্ত করবেন?

`data.js` ফাইলটি যেকোনো টেক্সট এডিটর (যেমন: Notepad বা VS Code) দিয়ে ওপেন করুন।  
সেখানে `BLOG_DATA` এর ভেতরে নিচের মতো করে একটি নতুন পোস্ট যোগ করুন:

```javascript
{
  id: 7, // পূর্বেরটির চেয়ে ১ বেশি দিন
  title: "আপনার ব্লগের শিরোনাম এখানে লিখুন",
  category: "শিক্ষা ও প্রস্তুতি", // অথবা আপনার পছন্দমতো ক্যাটাগরি
  date: "১৫ অক্টোবর ২০২৬",
  readTime: "৫ মিনিট পাঠ",
  coverImage: "https://images.unsplash.com/photo-1456513080510-7bf3a84b82f8?auto=format&fit=crop&w=800&q=80",
  summary: "এখানে আর্টিকেলের সংক্ষিপ্ত ২-৩ লাইনের বিবরণ দিন...",
  content: `
    <p class="mb-4">এখানে আপনার ব্লগের সম্পূর্ণ লেখা লিখুন...</p>
    <h3 class="text-xl font-bold mt-4 mb-2">উপশিরোনাম</h3>
    <p>আরও বিস্তারিত তথ্য...</p>
  `,
  downloadFile: {
    name: "আপনার_ফাইলের_নাম.pdf",
    type: "pdf", // pdf, zip, doc, excel
    size: "5.2 MB",
    downloads: 100,
    url: "https://drive.google.com/your-download-link" // এখানে Google Drive বা ক্লাউড লিংক দিন
  }
}
```

## 📥 গুগল ড্রাইভ থেকে ডাউনলোডের লিংক কীভাবে বসাবেন?

১. আপনার PDF, ZIP বা যেকোনো ফাইল **[Google Drive](https://drive.google.com)**-এ আপলোড করুন।  
২. ফাইলটির ওপর রাইট-ক্লিক করে **Share** > **Share**-এ যান।  
৩. General Access-এ **Anyone with the link** সিলেক্ট করে **Copy link** করুন।  
৪. `data.js` ফাইলে `url: "..."`-এর জায়গায় সেই কপি করা লিংকটি পেস্ট করে সেভ করুন। ব্যস, ভিজিটররা ক্লিক করলেই সরাসরি ডাউনলোড হয়ে যাবে!

## 🌐 ফ্রিতে ইন্টারনেটে আজীবনের জন্য লাইভ করার নিয়ম (০ টাকা খরচ)

এই ওয়েবসাইটটিতে কোনো জটিল সার্ভার বা ডাটাবেসের প্রয়োজন নেই। তাই এটি বিশ্বের সেরা ফ্রি ক্লাউড হোস্টিংগুলোতে হোস্ট করা যাবে।

### উপায় ১: GitHub Pages (সবচেয়ে জনপ্রিয় ও নিরাপদ)
১. [github.com](https://github.com)-এ একটি ফ্রি অ্যাকাউন্ট খুলুন।  
২. **New Repository** তৈরি করুন (যেমন নাম দিন: `my-free-site`)।  
৩. আপনার ফোল্ডারের সব ফাইল (`index.html`, `style.css`, `data.js`, `app.js`) সেখানে আপলোড করে Commit করুন।  
৪. এরপর রিপোজিটরির **Settings** > **Pages**-এ যান।  
৫. Source অপশনে **Deploy from a branch (main)** সিলেক্ট করে সেভ করুন।  
৬. মাত্র ২ মিনিটের মধ্যে আপনার ফ্রি ঠিকানা পেয়ে যাবেন:  
   👉 `https://yourusername.github.io/my-free-site/`

### উপায় ২: Vercel (সবচেয়ে সহজ ও দ্রুত)
১. [vercel.com](https://vercel.com)-এ ফ্রি সাইন আপ করুন।  
২. আপনার ফাইলগুলো ড্র্যাগ-অ্যান্ড-ড্রপ (Drag & Drop) করে দিলেই ১ ক্লিকে সাইট লাইভ হয়ে যাবে।  
৩. ঠিকানা হবে: 👉 `https://yourname.vercel.app`
